# 1. Introduction

## What is HTML?

HTML (**HyperText Markup Language**) is the standard markup language used to create web pages.

HTML describes the structure of a webpage using elements.

Example:

```html
<!DOCTYPE html>
<html>
<head>
    <title>My First Page</title>
</head>
<body>
    <h1>Hello World!</h1>
</body>
</html>
```
